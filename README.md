# ShineLux Cleaning Services Australia 🌟

Modern, high-performance web platform for **ShineLux Cleaning Services** — offering premium residential, commercial, and industrial cleaning across Australia.

## ✨ Features
- **Modern Tech Stack**: React 19, TypeScript, Vite, Tailwind CSS v4, GSAP Animations.
- **Brand Palette**: Custom luxury metallic gold theme matching the official ShineLux insignia.
- **Responsive Design**: Flawless experience across desktop, tablet, and mobile devices.
- **Service Catalog**: 15 specialized cleaning services with itemized transparent pricing.
- **Interactive Tools**: Dynamic Service Finder, Live Stats Counter, Marquee Trust Bar, and Customer Reviews Slider.
- **2-Step Online Booking & Free Quote Inquiries**.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm / pnpm

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
The site will run locally at `http://localhost:5173/`.

### Production Build
```bash
npm run build
```
Build output is saved to the `dist/` directory, ready for deployment on Vercel, Netlify, or any static hosting provider.
